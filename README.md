## Notas relacionadas con el backend

- Para la prueba utilice Visual Studio Code.

- El codigo fuente se encuentra en https://github.com/carlospedroza21/sisgestaskbe

- Para este componente utilice la tecnologia spring

- Dentro del paquete com.example.factory se encuentra la implementacion del patron de su mismo nombre.

- Dentro del paquete com.example.sisgestaskbe.observer se encuentra la implementacion del patros de su mismo nombre.

- Este componente no tiene la conexion a la BBDD de PostgreSQL. Trabaje con clases que se encuentran en el paquete com.example.sisgestaskbe.model.mock

- Los servicios no tiene pruebas unitarias.
